# 🎄 圣诞记忆树

基于 [moleculemmeng020425/christmas-tree](https://github.com/moleculemmeng020425/christmas-tree) 改造的 3D 粒子圣诞树（React + Three.js）。

## 功能

- **开场选择**：上传自己的照片，或者使用默认礼品图
- **上传照片**：支持多选和拖拽，自动裁成正方形并压缩；「用我的照片」只在你的浏览器里处理，不会上传到服务器（想让别人看到，用「大家的树」分享）
- **默认礼品**：树上挂满 18 种代码绘制的礼品插画（礼盒、泰迪熊、拐杖糖、铃铛、雪人、姜饼人、驯鹿、圣诞帽、小火车、水晶球、蜡烛、姜饼屋等），再加上你放进 `src/assets/gifts/` 的图片
- **点照片放大**：拍立得样式弹窗，可左右翻页（也可以用键盘 ← →，Esc 关闭）
- **点礼盒拆礼物**：点树上的小礼盒或树下的大礼盒，礼盒摇晃、开盖，弹出一份随机礼品
- **聚合 / 散开**：按钮切换，树会散成漫天粒子再重新聚合
- **专属贺卡链接**：写给谁、想说的话、署名，生成一个链接发给对方。对方打开后圣诞树聚合，出现信封，点开是贺卡和烟花。链接内容放在 `#card=` 后面（只在浏览器里解码，不会发到服务器）；只带文字，树用默认礼品装饰，上传的照片不会放进链接
- **大家的树 + 登录**：用户名 + 密码注册登录后，可以把照片分享到「大家的树」，打开网站的所有人（不用登录）都能看到挂满大家照片的圣诞树，点开能看到是谁分享的。上传者可以删自己的照片，管理员可以删任何一张、帮忘记密码的人重置密码
- **磨砂玻璃界面**：按钮、面板、弹窗都是半透明磨砂玻璃，圣诞树的光会透过来
- **三种语言**：右上角 EN / 中 / 日，默认英文，会记住上次的选择；打开贺卡链接时自动用写卡人的语言（不改掉你自己的设置）
- **手机适配**：竖屏时树会放大填满屏幕，欢迎页更紧凑；横屏时提示和按钮会缩小；触屏上提示「双指缩放」；输入框用 16px 字号，iPhone 不会自动放大页面；手机上画面分辨率略降，更省电更流畅
- **点星星有惊喜**：点树顶的金星，满屏烟花，弹出「圣诞快乐」，彩灯变成粉金色
- **手势控制**（默认关闭）：点「手势控制」后开启摄像头，左侧会出现手势说明面板，并高亮当前识别到的手势

  | 手势 | 效果 |
  | --- | --- |
  | ✊ 握拳 | 聚合成树 |
  | 🖐 张开手掌 | 散开 |
  | ↔️ 手左右移动 | 旋转圣诞树 |
  | ↕️ 手上下移动 | 俯仰视角 |
  | 🤏 拇指食指捏合 / 张开（其余三指弯曲） | 拉远 / 拉近 |
  | ☝️ 食指朝上 | 拆一个礼物 |
  | ✌️ 剪刀手 | 随机放大一张照片 |
  | 👍 点赞 | 下一张照片 / 再拆一个 |
  | 👎 拇指朝下 | 关闭弹窗 |
  | 🤟 彩蛋手势（拇指、食指、小指伸出） | 烟花彩蛋 |

  动作手势要保持约 0.3 秒才触发，触发一次后要换个手势才会再触发。说明面板里的大部分行可以直接点击，试一下效果。

## 账号和「大家的树」

后端跑在 Cloudflare Pages Functions 上（代码在 `server/`，入口 `functions/api/[[path]].ts`），账号和照片存在 Cloudflare D1 数据库 `christmas-tree`（`wrangler.jsonc`）。全部在免费额度内：

- 每张照片存一张 720px 大图（点开看）和一张 256px 小图（挂在树上），大约 0.2MB
- 树上挂最新的 80 张；每人最多 40 张，全站最多 1500 张（免费版数据库上限 500MB）
- 接口每天最多 10 万次请求（静态页面不算）；照片列表没变化时浏览器直接用缓存
- 密码用 PBKDF2 加盐哈希保存；同一账号 15 分钟内输错 8 次会暂时锁定

设置管理员（先在网站上注册，再运行）：

```bash
npm run admin -- 你的用户名
```

管理员登录后，点右上角的用户名可以帮别人重置密码；点开任何照片都能删除。

数据库结构在 `migrations/`，修改后运行 `npm run db:migrate`（线上）或 `npm run db:migrate:local`（本地）。

## 运行

```bash
npm install
npm run dev
```

连同账号和大家的树一起在本地运行（本地有一个单独的测试数据库）：

```bash
npm run db:migrate:local   # 第一次需要
npm run dev:api            # 打包并在 http://127.0.0.1:8788 运行完整网站
```

需要改界面时，再开一个终端运行 `npm run dev`，Vite 会把 `/api` 转给上面的本地服务。

打包成静态网页（输出在 `dist/`，可以直接部署到 Vercel、Netlify、GitHub Pages）：

```bash
npm run build
```

## 添加自己的默认礼品图

把图片放进 `src/assets/gifts/`，**文件名就是礼品名**（例如 `小火车.jpg`），重新运行即可。详见该文件夹里的 README。

## 文件结构

```
src/
  App.tsx                 页面状态：模式、弹窗、手势
  i18n.tsx                中 / 英 / 日文案和语言切换
  gifts/illustrations.ts  18 种礼品插画（Canvas 绘制）
  gifts/index.ts          默认礼品 = 文件夹图片 + 插画
  scene/                  3D 场景（树叶粒子、彩灯、金星、拍立得、礼盒）
  ui/                     欢迎页、照片/拆礼物弹窗、手势控制与说明面板、烟花
  utils/image.ts          上传图片的裁剪压缩
  api.ts / auth.tsx       调用后端接口、登录状态
server/                   后端：账号、照片、限流
functions/api/[[path]].ts Cloudflare Pages Functions 入口
migrations/               数据库结构
wrangler.jsonc            Cloudflare 配置（数据库绑定）
```

## 说明

- 手势模型（`public/mediapipe/gesture_recognizer.task`）、wasm 和花体字都从网站自己加载，不依赖 Google / jsDelivr，国内也能用。wasm 在 `npm run dev` / `npm run build` 前由 `scripts/copy-mediapipe.mjs` 自动从 node_modules 复制。
- 摄像头需要 https 或 localhost。
- 在线预览版（claude.ai 链接）不能用摄像头，也连不上后端，所以那里没有手势按钮、登录和大家的树；烟花彩蛋可以点星星触发。
- 分享到大家的树的照片是公开的：任何打开网站的人都能看到。
- 原仓库自带的照片是同一张真人肖像复制了 31 份，这里没有使用。
