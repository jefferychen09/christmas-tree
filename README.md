# 🎄 圣诞记忆树

基于 [moleculemmeng020425/christmas-tree](https://github.com/moleculemmeng020425/christmas-tree) 改造的 3D 粒子圣诞树（React + Three.js）。

## 功能

- **开场选择**：上传自己的照片，或者使用默认礼品图
- **上传照片**：支持多选和拖拽，自动裁成正方形并压缩；照片只在浏览器里处理，不会上传到服务器
- **默认礼品**：树上挂满 12 种代码绘制的礼品插画（礼盒、泰迪熊、拐杖糖、铃铛、雪人、姜饼人等），再加上你放进 `src/assets/gifts/` 的图片
- **点照片放大**：拍立得样式弹窗，可左右翻页（也可以用键盘 ← →，Esc 关闭）
- **点礼盒拆礼物**：点树上的小礼盒或树下的大礼盒，礼盒摇晃、开盖，弹出一份随机礼品
- **聚合 / 散开**：按钮切换，树会散成漫天粒子再重新聚合
- **专属贺卡链接**：写给谁、想说的话、署名，生成一个链接发给对方。对方打开后圣诞树聚合，出现信封，点开是贺卡和烟花。链接内容放在 `#card=` 后面（只在浏览器里解码，不会发到服务器）；只带文字，树用默认礼品装饰，上传的照片不会放进链接
- **磨砂玻璃界面**：按钮、面板、弹窗都是半透明磨砂玻璃，圣诞树的光会透过来
- **中英切换**：右上角 EN / 中，默认英文，会记住上次的选择
- **点星星有惊喜**：点树顶的金星，满屏烟花，弹出「圣诞快乐」，彩灯变成粉金色
- **手势控制**（默认关闭）：点「手势控制」后开启摄像头，左侧会出现手势说明面板，并高亮当前识别到的手势

  | 手势 | 效果 |
  | --- | --- |
  | ✊ 握拳 | 聚合成树 |
  | 🖐 张开手掌 | 散开 |
  | ↔️ 手左右移动 | 旋转圣诞树 |
  | ↕️ 手上下移动 | 俯仰视角 |
  | 🤏 拇指食指捏合 / 张开（其余三指弯曲） | 拉远 / 拉近 |
  | ☝️ 食指朝上 | 拆一个礼物 |
  | ✌️ 剪刀手 | 随机放大一张照片 |
  | 👍 点赞 | 下一张照片 / 再拆一个 |
  | 👎 拇指朝下 | 关闭弹窗 |
  | 🤟 彩蛋手势（拇指、食指、小指伸出） | 烟花彩蛋 |

  动作手势要保持约 0.3 秒才触发，触发一次后要换个手势才会再触发。说明面板里的大部分行可以直接点击，试一下效果。

## 在线访问

https://jefferychen09.github.io/christmas-tree/

推送到 `main` 分支后，GitHub Actions 会自动构建并重新发布（见 `.github/workflows/deploy.yml`），一两分钟后生效。

## 运行

```bash
npm install
npm run dev
```

打包成静态网页（输出在 `dist/`，可以直接部署到 Vercel、Netlify、GitHub Pages）：

```bash
npm run build
```

## 添加自己的默认礼品图

把图片放进 `src/assets/gifts/`，**文件名就是礼品名**（例如 `小火车.jpg`），重新运行即可。详见该文件夹里的 README。

## 文件结构

```
src/
  App.tsx                 页面状态：模式、弹窗、手势
  i18n.tsx                中英文案和语言切换
  gifts/illustrations.ts  12 种礼品插画（Canvas 绘制）
  gifts/index.ts          默认礼品 = 文件夹图片 + 插画
  scene/                  3D 场景（树叶粒子、彩灯、金星、拍立得、礼盒）
  ui/                     欢迎页、照片/拆礼物弹窗、手势控制与说明面板、烟花
  utils/image.ts          上传图片的裁剪压缩
```

## 说明

- 手势模型（`public/mediapipe/gesture_recognizer.task`）、wasm 和花体字都从网站自己加载，不依赖 Google / jsDelivr，国内也能用。wasm 在 `npm run dev` / `npm run build` 前由 `scripts/copy-mediapipe.mjs` 自动从 node_modules 复制。
- 摄像头需要 https 或 localhost。
- 在线预览版（claude.ai 链接）不能用摄像头，所以那里没有手势按钮；烟花彩蛋可以点星星触发。
- 原仓库自带的照片是同一张真人肖像复制了 31 份，这里没有使用。
